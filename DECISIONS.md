# Decisions

1. **Written fresh; the original notes used only for shape.** Jack's Startups 101 notes are marked restricted and
   lean on material from published books. The nine-module arc (founder's job → vision → validation → co-founders →
   MVP and launch → customers → mentors and updates → raising → team) follows the notes' outline; every sentence,
   example, quiz and template here is new. Nothing was copied.
2. **Do-the-work builders instead of reviewed submissions.** The v1 in the brief wanted accounts, reviews and
   certificates. Machine-driven mode has no server and no reviewer, so each module ends with a client-side builder
   that produces a document the learner keeps (copy, download, print). XP and progress are local.
3. **No promises, no credentials.** The original copy promised outsized outcomes; the FTC polices
   business-coaching earnings claims. Tests fail the build if module text or templates contain promise phrases
   ("guaranteed", "get funded", "millionaire"…). The course record says it is self-reported and not a credential.
4. **Legal and financial topics explained, not advised.** SAFEs, vesting, equity and hiring are taught as "how it
   commonly works", labeled as US practice where relevant, with "have a lawyer check real documents". The SAFE
   calculator states its simplified model and its test pins the math to a worked example.
5. **The "apply to be backed" CTA is a key, off by default.** It needs a real, open program page; when set, the
   copy says finishing the course doesn't change anyone's chances.
6. **Brand: Startup College, course: Startups 101.** It's Jack's brand (startupcollege.io is in the portfolio).
   Persist Ventures isn't named and no program claims are made.
7. **Templates double as search pages.** Each builder has its own URL with HowTo structured data; module pages
   are LearningResources inside a Course. No thin tag pages.
8. **Links checked weekly; content refreshed quarterly by a routine.** Gone links fail the weekly job; sites that
   refuse scripts only warn (they often block bots, not people).
9. **The course lives on a subdomain, `learn.startupcollege.io`.** `startupcollege.io` already serves the Start Up
   College site, so the course sits beside it instead of replacing it (the domain rollout session set it up on 22 Nov).
